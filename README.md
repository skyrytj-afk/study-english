# 📖 영어 리딩 (Study English)

간단한 영어 이야기를 **성우(브라우저 내장 음성)** 가 읽어주는 리딩 학습 웹 앱입니다.

## 주요 기능

- 🔊 **음성 낭독** — 브라우저 내장 TTS(Web Speech API)로 문장을 순서대로 읽어줍니다.
- 🐢 **속도 조절** — 0.5x ~ 1.5x 슬라이더로 리딩 속도를 조절합니다.
- 🇬🇧/🇰🇷 **자막 On/Off** — 영어 자막과 한글 자막을 각각 독립적으로 켜고 끌 수 있습니다.
- ✨ **현재 문장 하이라이트** — 지금 읽고 있는 문장을 강조 표시합니다.
- 🖱 **문장 클릭** — 원하는 문장을 클릭하면 그 문장부터 다시 읽습니다.
- 🎙 **음성 선택** — 브라우저가 제공하는 영어 음성 중에서 고를 수 있습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소(기본 http://localhost:5173)로 접속하세요.

> 음성 기능은 Chrome, Edge, Safari 최신 버전에서 가장 잘 동작합니다.
> 사용 가능한 영어 음성의 종류와 품질은 OS·브라우저에 따라 다릅니다.

## 콘텐츠 안내

샘플 이야기는 저작권 문제가 없도록 **학습용으로 새로 작성한 오리지널 텍스트**입니다.
문장별 영어/한글 번역이 매칭되어 자막 싱크가 정확합니다.
새 이야기는 `src/data/stories.ts`에 같은 형식으로 추가하면 됩니다.

## 기술 스택

- React + TypeScript + Vite
- Web Speech API (SpeechSynthesis)

## 폴더 구조

```
src/
├─ main.tsx              앱 진입점
├─ App.tsx               메인 화면 (리더 + 컨트롤)
├─ hooks/useSpeech.ts    Web Speech API 래핑 (문장별 낭독·속도·진행 추적)
├─ data/stories.ts       샘플 이야기 데이터 (영/한)
└─ styles.css            스타일
```
